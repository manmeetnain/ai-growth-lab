# AI Growth Lab

A standalone initiative — fully independent of the EdgeAIBus PhD research repo — aimed at three
outcomes: **money, startup access, and recognition/network**, in that priority order.

The bet: instead of scattering effort across many small projects, everything routes through
**one flagship build** ("the capstone") that becomes the credibility asset for every other track
(outreach, beta programs, content, events, consulting).

## Files in this folder

| File | Purpose |
|---|---|
| [STRATEGY.md](STRATEGY.md) | The overall flywheel — why one capstone, how the three tracks reinforce each other |
| [CAPSTONE.md](CAPSTONE.md) | The chosen flagship project: what it is, why it, MVP scope, how it's demoed |
| [ROADMAP.md](ROADMAP.md) | Week-by-week 90-day execution plan |
| [TARGETS.md](TARGETS.md) | Specific companies, beta/design-partner programs, and events to pursue |
| [OUTREACH.md](OUTREACH.md) | Ready-to-use templates for cold outreach, webinar pitches, event applications, freelance leads |

## How to use this

Start with STRATEGY.md once, then live in ROADMAP.md week to week. TARGETS.md and OUTREACH.md
are reference — pull from them as the roadmap tells you to reach out.

This folder is not a git repo yet. Run `git init` here if you want version history on the plan
itself; the capstone project's *code* should live in its own separate repo (see CAPSTONE.md),
not inside this planning folder.
