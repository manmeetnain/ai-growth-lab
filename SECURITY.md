# Security policy

Security fixes are applied to the latest supported code on the `main` branch.

## Report a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/manmeetnain/ai-growth-lab/security/advisories/new). Do not disclose suspected vulnerabilities in public issues, discussions, pull requests, or social posts.

Include the affected component, impact, reproduction steps, and a suggested mitigation when available. Remove credentials, personal data, customer data, and unrelated private information from evidence.

Only assess systems and data you own or are explicitly authorized to test. Reports involving third-party services should also be submitted to the affected provider.
